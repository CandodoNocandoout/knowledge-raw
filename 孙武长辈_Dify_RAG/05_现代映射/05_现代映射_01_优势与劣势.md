# 现代问题映射｜优势与劣势

## 一、现代用户可能如何提问

用户可能不会使用“不可胜”“可胜”“形”“势”等孙子术语，而会使用：

- 我现在没有优势怎么办？
- 对方比我强怎么办？
- 我的实力明显不如对方，还应该行动吗？
- 我现在处于劣势，应该怎么办？
- 双方实力差距很大，还有机会吗？
- 我没有胜算是不是就不应该做？
- 对方在资源、资金、人数上都比我强怎么办？
- 明明整体实力不如对方，怎么寻找突破口？
- 弱者有没有可能战胜强者？
- 我怎样才能把劣势变成优势？
- 我应该避开对方的优势吗？
- 如果正面竞争打不过，应该怎么办？

## 二、核心语义桥

现代问题中的：

“没有优势”
“对方比我强”
“实力不足”
“正面竞争处于劣势”
“没有胜算”

应优先联想到：

- 不可胜
- 可胜
- 先胜而后求战
- 先为不可胜
- 因敌变化
- 避实击虚
- 改变局部力量关系

## 三、对应孙子思想

### 1. 不可胜在己，可胜在敌

核心含义：

首先确保自己不处于容易被击败的状态，再等待或创造对手可以被击败的条件。

对应：

- 《军形篇》
- 《虚实篇》

### 2. 先胜而后求战

核心含义：

不是看到机会就立即行动，而是先创造足够有利的条件，再进入实际竞争。

对应：

- 《军形篇》

### 3. 先为不可胜，以待敌之可胜

核心含义：

当自身优势不足时，不应简单理解为“什么都不能做”，而应先建立安全边界、保存实力、改变条件，并等待或创造可胜条件。

对应：

- 《军形篇》

### 4. 避实击虚

核心含义：

如果正面面对对方的优势无法取得有利结果，则不应机械地进行正面竞争，而应寻找对方薄弱、空虚或不便发挥优势的位置。

对应：

- 《虚实篇》

## 四、现代问题 → 孙子概念

| 现代问题 | 应联想到的概念 |
|---|---|
| 我没有优势怎么办？ | 不可胜、先为不可胜 |
| 对方比我强怎么办？ | 不可胜在己、可胜在敌 |
| 正面打不过怎么办？ | 避实击虚 |
| 实力明显不如对方还能不能行动？ | 先为不可胜、寻找局部可胜 |
| 弱者有没有机会？ | 可胜在敌、因势、避实击虚 |
| 我应该直接和强者竞争吗？ | 先胜而后求战、避实击虚 |
| 如何把劣势变成机会？ | 因敌变化、因势、改变局部条件 |

## 六、孙伯分析时的基本原则

“没有优势”不等于“不能行动”。

应进一步分析：

1. 当前劣势来自哪里？
2. 哪些因素属于自己可以控制的范围？
3. 能否先建立不可胜？
4. 是否存在局部优势？
5. 是否可以避开对方优势？
6. 是否可以改变双方力量关系？
7. 是否可以等待或创造对手暴露弱点的条件？

不要把“实力弱”直接等同于“不能行动”。
